                    Note: gateway.api.bot.or.th doesn't send CORS headers, so a browser blocks calling it directly from this page (curl/Postman work fine because CORS is a browser-only restriction) — you'll get a generic "Failed to fetch" with no detail if you try without a proxy. Deploy the included bot-proxy-worker.js as a free Cloudflare Worker (paste its contents into a new Worker in the Cloudflare dashboard and deploy — no CLI needed), then paste the resulting *.workers.dev URL above. The worker only forwards to this one BOT endpoint and only forwards the Authorization header it's given, so your token doesn't go anywhere it doesn't already go. This pulls the BOT Daily Average Exchange Rate (THB to USD/EUR/SGD/AUD) for the selected month, and the daily THBT swap rates for every pair (using both the original and migrated pool IDs) from the Uniswap subgraph using the Graph API key entered above. The BOT Token field is required for the BOT columns (App ID isn't used in the request, but the field is kept in case a future BOT endpoint needs it) — leave the token blank to generate the report with just the LP data. The "Exchange to THB" columns mirror the template layout but have no data source defined yet, so they are left blank.
